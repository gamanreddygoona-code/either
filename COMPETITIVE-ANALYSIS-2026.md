## 🔍 Deep Dive: Each Competitor

### 1. Claude Code (Anthropic)

**What it is:** An agentic coding tool that lives in your terminal, reads your entire codebase, edits files, runs commands, and ships features.

**Key Features:**
- Reads entire codebases and understands context
- Plans changes across multiple files
- Runs tests and fixes its own errors
- Terminal-native, works in IDE and browser
- Multi-file refactoring at scale
- Agent loop: generates → executes → observes → corrects

**Pricing:**
| Plan | Price | What You Get |
|------|-------|-------------|
| Pro | $20/mo | Claude Code access, standard usage |
| Max 5x | $100/mo | 5x more usage |
| Max 20x | $200/mo | 20x more usage |
| Team Premium | $100/seat/mo | Team collaboration |
| API | Pay-per-token | $3/$15 per 1M tokens (Opus 5) |

**Strengths:**
- Best coding model (Claude Opus 5 = #1 Arena WebDev 1702.9)
- Understands entire repos, not just snippets
- Self-correcting agent loop
- Multi-git-worktree parallel task execution
- Production-ready: tests, CI/CD integration

**Weaknesses:**
- **Coding only** — no email, no Slack, no Notion connectors
- **No trading/finance** — can't analyze markets
- **No marketing** — no CMO agents, no content creation
- **No persistent memory** — starts fresh each session
- **Expensive** — $200/mo for heavy use

- Free tier available
- Supports Llama, Mixtral, Gemma models

**Pricing:**

## 💡 Recommended Strategy: What to Build Next

### Phase 1: Multi-Model (Week 1)
Add Groq (speed), Claude (quality), GPT-5.6 (reasoning) alongside Gemini. This closes the biggest gap — model choice.

### Phase 2: Persistent Agents (Week 2-3)
Upgrade from interval-based to always-on agents with context persistence. This matches Grok Bot's core advantage.

### Phase 3: MCP Server (Week 3-4)
Expose your 15 connectors as MCP tools. Any AI agent (Claude, ChatGPT, Grok) can then use your connectors. This makes Littlebird the connector layer for the entire AI ecosystem.

### Phase 4: Mobile PWA (Week 4-5)
Progressive Web App with offline support. Matches mobile parity without native app development.

### Phase 5: Browser Automation (Week 5-6)
Add Playwright/Puppeteer integration for web scraping, form filling, and workflow automation. Matches Grok Bot's "teach a task."

## 🏆 Bottom Line

**Littlebird is the only self-hosted, free, multi-connector AI workspace with trading and marketing agents.** No competitor offers all of these in one app.
